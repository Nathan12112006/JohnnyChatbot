# Johnny - AI Resume Assistant Chatbot

Meet Johnny, your friendly AI assistant who knows all about my background, projects, and experience. He's here to convince you why you should hire me!


[Chat with Johnny] (https://johnny-chatbot.onrender.com)

Note: First load may take 30-60 seconds as the service spins up from sleep mode (free hosting tier).

## 💬 What Johnny Can Tell You About

- My technical projects and achievements
- Programming skills and technologies I know
- Educational background and coursework
- What makes me unique as a candidate
- Funny coding stories and experiences

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: FastAPI (Python)
- AI: OpenAI GPT API
- Deployment: Render (Backend), Static hosting (Frontend)
- Features: Real-time chat, typing indicators, suggestion buttons

## Features

- Intelligent Responses: Johnny understands context and provides relevant information
- Personality: Friendly, witty, and professional tone
- Interactive UI: Modern chat interface with typing indicators
- Quick Suggestions: Clickable suggestion buttons for common questions
- Mobile Responsive: Works great on all devices
- Real-time Chat: Smooth conversation flow with animations

## About Johnny

Johnny is designed to showcase my technical skills while providing an engaging way for potential employers to learn about my background. He's programmed with my actual resume data, project details, and personality to give authentic responses about my qualifications and experience.
